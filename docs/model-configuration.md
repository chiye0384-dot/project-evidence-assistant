# 模型配置

`run.py` 默认以模型未配置状态启动。网页的登记、公开来源核验、源码工具和已存内容浏览可以独立使用。

真实模型功能使用官方 DeepSeek。`scripts/Start-WithDeepSeek.ps1` 在本机终端隐藏输入 Key。目录和章节请求按既有适配器选择官方路径，两阶段追问的严格函数载体使用 `https://api.deepseek.com/beta/chat/completions`，访问检查使用 `https://api.deepseek.com/models`。

付费入口要求使用者核对当前模型、官方价格和用途。代码中的价格 profile 是开发时固定的实验配置，启动时必须具备新鲜、匹配的 `prices/deepseek-verified.json`，通过价格和费用门禁后才会启用模型。本发布副本提供源码与实验入口，首次运行优先使用默认无 Key 模式。

价格凭据字段由 `spending.py` 的 `refresh_verified_price` 校验，含模型、币种、输入和输出单价、官方价格页 URL、原响应 SHA256、核验时间和到期时间。价格变动须复核代码配置。不要把过期凭据改成新时间。

费用以本机 `data/` 中的同一账本累计。删除一个学习对象不会删除费用记录。开发实验的使用上限与真实平台余额分别核对。模型凭据通过进程内适配器使用，不写入前端或源码证据。

四类章节分别由用途开关启用。追问还需要对应主题开关，两阶段模式、选行表、正文载体及位置视图有各自的显式参数约束。可通过 `run.py --help` 查看接口。完整模型质量验收仍在进行。

0.4.1 新增 `--followup-prose-flat`（PowerShell 入口为 `-FollowUpProseFlat`）。它需要 `--followup-two-phase`，并与原 `--followup-prose-kind` 互斥。平铺格式把冻结块映射为 `i1,h1,t1` 等显式字段，仍检查块编号、数量、文本长度、引用及原始预算；不从旧格式猜测或补全结果。原 kind/indexed 格式继续支持，默认行为不改变。

选行表规划把证据 ID 约束在当前成功且未截断的读取内。缺口和无依据候选只允许文字片段，不提供不存在的引用位置指针；文字仍可能包含不受支持的内容，因此本地行号校验和源码辅助评审继续执行。一次 F03 隔离候选在2026-11-08完成并通过开发题7条源码辅助评审，不能据此保证所有后续问题正确。

已有开发工作区升级时需保留原 `data/` 费用账本、授权和真实价格凭据，不能通过新克隆目录重新获得预算。公开源码没有附带开发者的数据库、Key、费用回执或实验档案；本发布副本的工程测试使用独立合成数据，没有迁移原工作区或重新调用付费模型。

版本升级沿用原有历史规则：旧正文保留可读，但生产版本不匹配时会标为需复核，不能直接用作新版本追问的父正文。旧格式兼容表示仍可显式选择原 kind/indexed 载体，不会自动提升旧内容的质量或有效状态。
